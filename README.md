# 我们会和好吗？

一场关于友情的心理测试。19 道题，给出 1%-99% 的「和好概率」和一份关系分析。

## 在线访问

https://lxnnn.github.io/friendship-test/

手机端打开即可，微信 / 抖音内置浏览器也支持。

## 文件说明

- `index.html` — 测试主文件（单文件，无外部依赖）
- `main` 分支 — 源码
- `gh-pages` 分支 — GitHub Pages 发布分支

## 说明

- 单文件 HTML，手机端优先
- 不联网、不收集数据，答案只保存在浏览器本地
- 这是一个基于关系心理学视角的娱乐测试，不构成任何建议或预测
- 分享卡支持长按保存到相册
